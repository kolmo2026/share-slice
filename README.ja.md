# Share Slice

[English](README.md) · [日本語サイト](https://filings.optmodel.com/ja/)

ブラウザー内で株数シナリオを計算します。新株発行、RSU権利確定、全額行使、自社株買いを順に反映し、各段階を確認してJSON条件を保存・再読込できます。

## 導入と実行

Node 24以降とnpmが必要です。依存関係の取得時には通信します。

```sh
git clone https://github.com/kolmo2026/share-slice.git
cd share-slice
npm ci
npm run build
npm run serve -- --port 4173
```

サーバー起動後にhttp://127.0.0.1:4173を開きます。停止はCtrl+Cです。

## 再現できる例

**入力：** 開始1億株、保有100万株、期間利益2000万米ドル。1000万株の発行と500万株のRSU権利確定。

**出力：** 期末1億1500万株、持分0.869565%、株数増加15%、相対持分希薄化13.043478%、持分低下0.130435ポイント、簡易EPS 0.173913米ドル。

サンプル：examples/scenario.json。同梱文書と数値はすべて合成例です。

## テストとビルド

```sh
npm test
npm run build
```

サイトの編集元は`site/`、生成手順は`scripts/`です。ツール実装は`src/`、核となるテストは`test/`にあります（blogには計算エンジンはありません）。独立した静的サイトを`docs/`に生成し、英日対応ページ、canonical/hreflang、sitemap、robots、CNAME、.nojekyllを含めます。公開用ホストはhttps://filings.optmodel.comです。隣のリポジトリに依存せず単独でビルドできます。

公開ソースはGitHub、現在の学習用サイトはVercelでホストしています。以前のGitHub Pages設定と互換ファイルは保持していますが、現在の本番ホスティングではありません。

## 制約

保有株数と期間利益を固定します。期末株数であり加重平均ではありません。全額行使は自己株式方式ではありません。反希薄化、税効果、利益調整はなく、法定希薄化後EPSではありません。通貨はラベルのみです。株数は安全整数、結果は浮動小数点です。相場データや投資助言は提供しません。

## プライバシーと関連製品

アカウント、アクセス解析、バックエンド、文書のアップロード先はありません。計算とファイル処理はローカルです。ただし公開サイト資源の取得には通信します。ブラウザー依存ライブラリーは同梱し、実行時CDNは使いません。JSONは平文なので、共有前にファイル名や条件を確認してください。

[Eqvero](https://eqvero.com/)：公開開示を使う調査サービスで、この算数ツールとは別です。

GitHubアカウント**kolmo2026**を通じて、Eqvero・KolmoPDF・KomoPDF向けツールを開発する同じ保守チームが管理しています。独立した第三者レビューや推薦ではありません。KolmoPDFのクラウド処理は文書をアップロードする別サービスです。
