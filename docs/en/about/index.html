About this site

Share Slice Notes publishes practical tools and notes for financial research and document workflows. Explore the examples, inspect the source and use the documented limits when applying a result.

Local processing and privacy

The tools perform their documented calculations or file operations locally. This static site has no login, document-upload endpoint, analytics script or database. Loading the site requests its public HTML, styles and JavaScript from the hosting provider. External services have their own processing policies; KolmoPDF uploads documents for cloud conversion.

Source and examples

Source code and synthetic examples are available under MIT. Financial scenarios are not investment advice. A structural document check does not establish factual accuracy.
