A Share Scenario Is Not Reported Diluted EPS

kolmo2026 · About

Published 2026-11-03 · Updated 2026-11-04

Share Slice answers a narrow question: if these share-count events happened and one holder’s shares did not change, what would the period-end proportions look like? It does not reproduce an earnings-per-share disclosure.

The arithmetic

Let S₀ be starting shares, S₁ the current scenario’s shares, H the unchanged holding, and I the unchanged period income. Each issuance, RSU vesting or full exercise adds the entered shares. A buyback subtracts them.

Ownership % = 100 × H / S₁
Share growth % = 100 × (S₁ / S₀ - 1)
Ownership dilution % = 100 × (1 - S₀ / S₁)
Ownership drop (pp) = 100 × H / S₀ - 100 × H / S₁
Simple EPS = I / S₁

For a zero-share holder, the displayed dilution rate describes the relative effect on a hypothetical unchanged nonzero holding; actual ownership remains zero. A buyback can make the dilution figure negative, meaning an ownership increase rather than a loss. Loss-making income is allowed, but a less negative per-share loss is not evidence that shareholder value improved.

What a financial statement may do differently

The tool does not weight shares by the fraction of the reporting period they were outstanding. It does not implement treasury-stock treatment, proceeds-based repurchases, if-converted adjustments, tax effects, changes to the earnings numerator or anti-dilution rules. An “exercise” event is a full issuance assumption, not a claim that all options belong in reported diluted EPS.

Check a scenario before relying on it

  1. Use actual share counts, not values in millions unless every share input uses that same unit. The supplied example uses individual shares.
  2. Use income and currency from one stated period. The currency field is a label, not an exchange-rate conversion.
  3. If you participate in a rights offer or sell shares in a buyback, the unchanged-holder assumption fails. Rebuild the scenario outside this tool.
  4. Read the share note and EPS note in the original disclosure before comparing the output with a reported number.

Inputs are safe integer share counts; results use JavaScript floating-point arithmetic and display six decimals. Saved JSON contains your inputs in plain text. Do not publish a scenario that contains confidential financial assumptions.

For the source-reading step, research public disclosures with Eqvero. Verify the period, share note and earnings definition before using a disclosed figure as a scenario input; neither this link nor the calculator turns the output into statutory diluted EPS.
