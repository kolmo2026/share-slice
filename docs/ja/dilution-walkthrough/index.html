発行済株式数が15%増えても、持分が15%減るわけではない

kolmo2026保守チーム · 運営・関連性の開示

公開 2026-11-03 · 更新 2026-11-04

編集上の更新：方法記事で関連製品への案内を明確化し、保守者、日付、同サイトの関連記事を追加しました。計算やファイル処理の動作は変更していません。

新株発行では分母が変わります。しかし「15%の希薄化」と書かれていても、何を分母にした数字か分からないことがあります。相場データなしで再計算できる合成例で、三つの変化を分けてみます。

条件を入力する

  1. ローカル計算機でサンプルを読み込みます。
  2. 開始時の総株数を100,000,000株、自分の保有を1,000,000株とします。
  3. 同じ一期間の純利益を20,000,000米ドルに固定します。
  4. 10,000,000株の新株発行と、5,000,000株のRSU権利確定を順に追加します。期末までに全数が反映され、自分には割り当てられない前提です。

三つの数字を読む

期末株数 = 100,000,000 + 10,000,000 + 5,000,000
         = 115,000,000株
株数増加率 = (115 / 100 - 1) × 100 = 15%
開始時の持分 = 1 / 100 × 100 = 1%
期末の持分 = 1 / 115 × 100 = 0.869565%
相対的な持分希薄化率 = (1 - 100 / 115) × 100
                    = 13.043478%
持分の低下 = 1% - 0.869565% = 0.130435ポイント

株数は15%増えました。一方、自分の持分は開始時との比較で約13.04%減っています。持分の絶対的な変化は約0.130435ポイントです。同じ変化を別の分母で表した数字なので、そのまま置き換えることはできません。

自社株買いを加えて条件を保存する

次に6,000,000株の自社株買いを追加すると、期末株数は109,000,000株、持分は約0.917431%になります。自分は買い戻しに応じない前提です。JSONシナリオを保存して再読込し、イベントの順序と入力が戻ることを確認します。このJSONが残すのは条件であり、開示資料の検証や株価予測ではありません。

利益を固定した元の1億1500万株の例では、期末株数による簡易EPSは0.173913米ドルです。法定の希薄化後EPSではありません。実際の開示と照合する調査には、同じエコシステムの関連サービスであるEqveroの分析機能もあります。シナリオの前提を差し替える前に原資料を読んでください。
